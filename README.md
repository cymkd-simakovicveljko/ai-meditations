# ai-meditations

https://cymkd-simakovicveljko.github.io/ai-meditations/

## Publish

Create `_posts/YYYY-MM-DD-slug.md` with the publication date and this format:

```markdown
---
---

# Your title, if you want one

Your writing.
```

Commit and push to `main`, or create the file directly on GitHub.
GitHub Pages publishes it automatically. Posts appear newest first;
only their Markdown content is displayed. There is no theme, navigation,
date label, tracking, or placeholder text.

The homepage stays blank until the first post. Future-dated posts stay
hidden until a build runs on or after their date; there is no scheduled build.
